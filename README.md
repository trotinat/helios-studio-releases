# Helios Studio

Installateurs Windows et mises à jour de Helios Studio — BC Skills Group.

## Installation

Téléchargez le fichier `Helios-Studio-Setup-…-x64.exe` depuis la [dernière release](https://github.com/trotinat/helios-studio-releases/releases/latest), puis ouvrez-le pour installer l’application. Windows x64. L’installateur actuel est non signé.

## Mises à jour

Les versions installées recherchent les mises à jour automatiquement. Le bouton **Mises à jour** permet également de vérifier, télécharger, puis choisir **Installer et redémarrer**. À partir de la 1.0.2, une petite notification annonce les nouvelles versions disponibles.

Pour passer de la 1.0.0 à la 1.0.2 : **Mises à jour → Vérifier → Télécharger → Installer et redémarrer**. Utilisez la version installée avec le Setup.

## Données et comptes

Chaque utilisateur utilise ses propres comptes Helios. Les comptes, mots de passe, fichiers Excel et données de travail ne sont pas distribués dans ce dépôt. Les données locales sont conservées lors des mises à jour.

Ce dépôt contient les installateurs et leurs fichiers de mise à jour. Le code source de l’application est conservé séparément.
