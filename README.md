# Helios Studio

Installateurs Windows et mises à jour de Helios Studio.

## Installation

Téléchargez le fichier `Helios-Studio-Setup-…-x64.exe` depuis la dernière release stable, puis ouvrez-le pour installer l’application.

Aucune version n’est encore publiée : le dépôt prépare la prochaine distribution.

## Mises à jour

Les versions distribuées recherchent les mises à jour automatiquement. Le bouton **Mises à jour** permet également de vérifier, télécharger, puis choisir **Installer et redémarrer**.

## Données et comptes

Chaque utilisateur utilise ses propres comptes Helios. Les comptes, mots de passe, fichiers Excel et données de travail ne sont pas distribués dans ce dépôt.

Le dépôt contient uniquement les installateurs et leurs fichiers de mise à jour. Le code source est conservé séparément.
